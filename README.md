# Task 5: Data Analysis on CSV Files

## Sales Data Analysis Using Python and Pandas

This project performs sales data analysis using Python, Pandas, and Matplotlib. The objective is to analyze sales data, identify important patterns, and generate useful insights through data processing and visualization.

## Objective

To analyze sales data using Pandas and understand product-wise sales, region-wise sales, monthly sales trends, and other important information from a CSV dataset.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV

## Dataset

The dataset contains the following fields:

- **Date** – Date of the sales transaction
- **Product** – Product sold
- **Region** – Sales region
- **Quantity** – Quantity of products sold
- **Unit_Price** – Price per unit
- **Sales** – Total sales amount

## Analysis Performed

The following analysis was performed in this project:

1. Loaded the CSV dataset using Pandas.
2. Inspected the dataset using `head()` and `info()`.
3. Checked the dataset shape using `shape`.
4. Generated a statistical summary using `describe()`.
5. Checked for missing values using `isnull().sum()`.
6. Performed product-wise sales analysis using `groupby()`.
7. Performed region-wise sales analysis.
8. Analyzed monthly sales trends.
9. Identified the highest-selling product and region.
10. Filtered sales records based on sales value.
11. Selected data using `loc`.
12. Selected data using `iloc`.
13. Analyzed total quantity sold by product.
14. Created visualizations using Matplotlib.

## Key Findings

- **Laptop** generated the highest total sales.
- **North** region recorded the highest total sales.
- Monthly sales showed an increasing trend from January to May.
- No missing values were found in the dataset.
- The total sales generated by the dataset were **₹3,065,300**.
- The total quantity of products sold was **315**.
